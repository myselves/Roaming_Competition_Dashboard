# 스모크 테스트 프롬프트

예약 작업을 등록하기 전에 **수집 경로가 살아 있는지만** 빠르게 확인하는 용도다.
전체 갱신(6개사 × 인덱스 9종)은 오래 걸리므로, 수집 방식이 서로 다른
대표 5개 소스로 먼저 검증한다. 이 5개가 통과하면 나머지는 같은 방식의
변형이라 통과할 가능성이 높다.

| 소스 | 검증하는 것 |
|---|---|
| 핀다이렉트 | z-api JSON API + 옵션 매칭(무제한·기간·최저가) |
| 유심사 | 홈 타일 JS 클릭 → SPA 상품 페이지 → 기간 버튼 클릭 (가장 깨지기 쉬움) |
| 로밍도깨비 | document.body.textContent 가격 사다리 추출 |
| 말톡 | 고도몰 3단 연쇄 select 조작 + 기본가·가산액 합산 |
| 유심스토어 | 라이브 DOM 렌더 목록 + 온라인특가·옵션 가산 합산 |

## 실행 방법

**Claude Desktop 앱에서 일반 세션으로** 실행한다. 예약 작업과 같은 환경
(Cowork 세션 + claude.ai 계정 스킬 + 로컬 Chrome)이라야 의미 있는 테스트가 된다.
터미널 CLI로 돌리면 스킬을 읽는 경로가 달라 예약 작업 환경을 검증하지 못한다.

아래 프롬프트에서 `<저장소 경로>` 만 실제 클론 위치로 바꿔 붙여넣는다.

## 프롬프트

```text
[로밍 대시보드 — 스모크 테스트 (수집만, 파일 수정 금지)]

작업 폴더: <저장소 경로>

목적: 주간 자동 갱신을 걸기 전에 수집 경로가 살아 있는지만 확인한다.
파일을 절대 수정하지 말고 커밋·푸시도 하지 말 것. 결과만 보고하라.
전량 수집도 하지 말 것 — 아래 지정한 표본(일본 인덱스 1종)만 확인한다.

0. roaming-dashboard-update 스킬이 로드되는지 확인한다. 로드되지 않으면
   즉시 중단하고 "스킬 미로드"라고 보고하라. 스킬의
   references/data-sources.md 를 읽고 아래 수집 방법을 그대로 따른다.

1. /chrome 으로 Claude in Chrome 연결 상태를 확인한다. 미연결이면 중단하고
   보고하라.

2. 핀다이렉트 (data-sources §1)
   z-api /roaming/products 에서 일본 productId를 찾아 옵션에서
   "일본 5일 무제한" 최저가를 계산한다.
   기대값: 13,300원 (2026-07-31 기준)

3. 유심사 (data-sources §2)
   홈에서 "무제한일본" 타일 클릭 → 상품 페이지에서 "5일" 명시 클릭 →
   완전 무제한 가격을 읽는다.
   기대값: 16,100원 (2026-07-31 기준)

4. 로밍도깨비 (data-sources §4)
   /esim/463 (일본 로밍) — 페이지 제목·본문에 "일본"이 있는지 먼저
   확인(ID 어서션)한 뒤 textContent에서 올데이 사다리의 5일 값을 읽는다.
   기대값: 14,000원 (2026-07-31 기준)

5. 말톡 (data-sources §5)
   store.maaltalk.com goods_view goodsNo=1000000265 — 제목에 "일본" 확인 후
   3단 select로 KDDI/Softbank 무제한 5일 최저가를 계산한다.
   기대값: 16,300원 = 기본가+일수 가산 (2026-07-31 기준)

6. 유심스토어 (data-sources §6)
   item_list.php?ca_id=2010f0 (일본 eSIM) 라이브 DOM에서 무제한 상품의
   온라인특가 + 5일 옵션 가산액을 계산한다.
   기대값: 10,000원 = 2,000 + 8,000 (2026-07-31 기준)

각 항목은 실패해도 중단하지 말고 끝까지 진행한 뒤 종합 보고하라.

보고 형식:
[스모크 테스트 결과]
스킬 로드: O/X
Chrome 연결: O/X
① 핀다이렉트 API: O/X (실측값)
② 유심사 SPA 클릭: O/X (실측값)
③ 로밍도깨비 사다리: O/X (실측값)
④ 말톡 3단 select: O/X (실측값)
⑤ 유심스토어 라이브 DOM: O/X (실측값)
종합 판단: 전체 실행 가능 / 불가 (사유)
```

## 결과 해석

- **전부 O** → `docs/scheduled-task-prompt.md` 로 전체 실행을 한 번 돌린다
- **기대값과 다른 숫자가 나옴** → 가격이 실제로 바뀐 것일 수 있다(로밍 가격은
  변동이 잦다). 자릿수 범위가 비슷하면 정상 — 전체 실행에서 가드가 급변 여부를
  다시 판정한다
- **특정 사이트만 X** → 사이트 개편 가능성. 전체 실행은 진행하되(스킬이 실패
  브랜드는 직전값 이월로 처리한다) 해당 소스의 수집 방법을 다시 찾아야 한다
- **스킬 미로드 / Chrome 미연결** → 전체 실행 금지. 환경부터 해결한다
